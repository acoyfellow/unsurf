import { Card, CardGrid, Tabs, TabItem } from '@astrojs/starlight/components';

Unsurf discovers a browser repro, promotes only observed behavior, and independently confirms the fix.

<div class="hero-snippet">

<Tabs>
  <TabItem label="Investigate">
```bash
unsurf investigate \
  --symptom "The response looked complete, then continued" \
  --broken "$BASELINE_URL" \
  --fixed "$CANDIDATE_URL"
```
  </TabItem>
  <TabItem label="Replay">
```bash
unsurf replay .unsurf/runs/abc123/repro.json \
  --target "$PREVIEW_URL" --runs 3
```
  </TabItem>
  <TabItem label="Doctor">
```bash
unsurf doctor
```
  </TabItem>
</Tabs>

</div>

<CardGrid>
  <Card title="Parallel discovery" icon="magnifier">
    Several causal investigators explore a vague symptom in independent browser surfaces.
  </Card>
  <Card title="Fresh confirmation" icon="rocket">
    Only an observed candidate is replayed three times against broken and fixed targets.
  </Card>
  <Card title="Portable repro" icon="document">
    `repro.json` is the deterministic contract. Model prose is never confirmation.
  </Card>
  <Card title="Evidence-backed" icon="open-book">
    Every run emits screenshots, state timelines, a machine receipt, and a reviewer report.
  </Card>
  <Card title="Authenticated browser" icon="laptop">

  </Card>
  <Card title="Hosted execution" icon="cloud-download">

  </Card>
</CardGrid>

## What comes back

```text
✓ Candidate observed
✓ Broken reproduced 3/3
✓ Fixed reproduced 0/3

Repro:  .unsurf/runs/<id>/repro.json
Report: .unsurf/runs/<id>/report.md
Result: .unsurf/runs/<id>/result.json
```

Reproducibility is mandatory. Video is optional evidence determined by provider capabilities.
