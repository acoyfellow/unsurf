## One system, three layers

```text
authenticated browser
        ↓
agent action
        ↓
video + trace + receipt
        ↓
optional typed API seam
```

1. **Browser** — act in the real authenticated session.
2. **Proof** — record, inspect, and loop until the task is done.
3. **Seams** — turn stable website behavior into typed, reusable interfaces.
