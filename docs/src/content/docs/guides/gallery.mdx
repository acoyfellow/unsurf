---
title: Using the Directory
description: Browse and share reusable API seams discovered by Unsurf.
---

The Directory is where Unsurf stores reusable website seams: typed API surfaces captured when direct HTTP replay is useful.

## What belongs here

Directory entries make sense when:

- a website exposes a stable API beneath its UI
- that API is useful to repeat later
- sharing the seam saves other agents from rediscovering it

They are complementary to the browser runtime, not a replacement for it.

## Search

```bash
curl "https://unsurf-api.coey.dev/search?q=payment+processing"
curl "https://unsurf-api.coey.dev/d/api.stripe.com"
```

## Publish

After a successful scout, publish the captured seam when it is broadly useful:

```bash
curl -X POST "https://unsurf-api.coey.dev/d/publish" \
  -H "Content-Type: application/json" \
  -d '{"siteId":"site_abc123","contributor":"your-name"}'
```

## Agent guidance

A good agent asks:

1. Do I need the user's live browser session? Use local MCP.
2. Do I need a proof artifact? Record or loop.
3. Is there a stable HTTP seam worth reusing? Search the Directory or scout one.

That third case is where the Directory shines.
